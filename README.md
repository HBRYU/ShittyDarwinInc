#As the name suggests, this is not a professional research project.

Rather, this is a samll hobby simulation that developed into something interesting enough to share.

#NEAT
stands for NeuroEvolution of Augmented Topologies, and it is the primary algorithm I used to evolve intelligent agents accross various environments:

- Ecosystem with agents that search for food to survive and reproduce
- 2-team large-scale shooter game to simulate competitive evolution
- 2D Drone simulation for learning complex physical controls via evolution

This project features a neural network system with built in mutation and crossover functions, along with a live visualizer to enable real-time analysis of the networks.
